# Horizon

**Horizon** is a personalized AI career advisor that maps skills, recommends career paths, and prepares students for the evolving job market.

How to run on your device
1. Clone the Repository in your local device.
```shell
git clone https://github.com/Mayank2177/Horizon.git
```
2. Navigate to Frontend folder.
```shell
cd Client

3. Download the required Dependencies.
```shell
npm install

4. Start the development server (Run).
```shell
npm run development
